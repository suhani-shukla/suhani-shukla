## `whoami`

B.Tech student in **Computer Science & Engineering — Cyber Security and Digital Forensics** at **Vellore Institute of Technology, Bhopal**, Aug 2023 – May 2027. I work at the intersection of security and software — building tools that detect, investigate, and respond to threats, backed by hands-on forensic and incident-response experience.

Most recently, I was a **Cyber Cell Intern at Crime Branch, Indore Police**, where I investigated phishing, online fraud, and social media misuse cases — collecting and preserving digital evidence under standard forensic protocols, and authoring technical case reports. Before that, as a **Cybersecurity Intern at The Red Users**, I monitored live network traffic with Wireshark, ran vulnerability assessments with OWASP ZAP and WebGoat, and hardened server configurations by tightening firewall rules.

I'm a **Google Cybersecurity Professional Certificate** holder, and I build full-stack security tooling in Python — from real-time SIEM correlation engines to threat-intel platforms.

## Projects

### SIEM Dashboard — Real-Time Threat Detection Platform
> Python · FastAPI · PostgreSQL · Redis · React · Docker

Full-stack, real-time correlation engine detecting 4 MITRE ATT&CK-mapped attack patterns (brute force, DNS tunneling, phishing, privilege escalation) using Redis sliding-window algorithms. REST API backend paired with a React dashboard featuring live Server-Sent Events alert streaming, audit-trailed alert lifecycle management, and an attack simulation engine — containerized end-to-end with Docker Compose.

**[Code →](https://github.com/suhani-shukla/SIEM-Dashboard)**

---

### File Metadata Analyser & Threat Intelligence Platform
> Python · Flask · PostgreSQL · VirusTotal API v3

Flask-based REST API and web app that extracts file metadata, computes MD5/SHA-256 hashes, and classifies files via the VirusTotal API v3 — with results persisted in a normalized PostgreSQL evidence schema for efficient querying.

**[Code →](https://github.com/suhani-shukla/File-Metadata-Analyser)**

---

### Cipher Suite
> Python · Tkinter · Cryptography

Six classical cipher algorithms implemented for encryption and decryption, with a responsive Tkinter GUI, input validation, and a modular, OOP-based architecture.

**[Code →](https://github.com/suhani-shukla/CipherSuite)**

---

### Cancer Classification Using Gene Expression Data
> Python · Scikit-learn · Machine Learning

ML classification model trained on gene expression data to predict tumor types, supporting early-stage cancer diagnosis research through data preprocessing and rigorous model evaluation.
